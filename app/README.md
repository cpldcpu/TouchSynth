# TouchSynth Poly: browser app

Editor, librarian and console for TouchSynth Poly, in the browser: patch editing (all parameters of
[docs/midi.md](../docs/midi.md) section 4), the 64 programs, the 8 parts, the cards' status and calibration, an
on-screen keyboard, a MIDI monitor and the CDC console. Requirements and architecture: design report, sections
"Host software" (HS1–HS11). Status: first version (2026-10-20), with a built-in **emulator** of the instrument.

## Use

Open `index.html` in Chrome or Edge (Web MIDI and Web Serial need a Chromium-based browser). It opens straight from
disk; no server, no build step, no network access. Or serve the folder (`python -m http.server` in `app/`, then
`http://localhost:8000`).

- **Emulator** (the default): an emulated instrument in the page answers everything the real one will (programs,
  parts, six voice cards in slots 1–6), and **Sound: on** plays it through the computer's audio, a Web Audio
  approximation of the voice cards (not their DSP: no PWM, two biquads for the ladder).
- **Real instrument**: *Find MIDI* (the browser asks for MIDI and SysEx permission), pick the "TouchSynth Poly"
  port, *Connect*. The controller firmware does not implement the SysEx messages yet (docs/sysex.md); the bench
  controller answers the identity request and plays notes and program changes.

Keyboard: the on-screen keys, or the computer keys A W S E D F T G Y H U J K (Z / X shift the octave), on the MIDI
channel of the part selected at the top. `index.html#library` (or `#setup`, `#instrument`, `#monitor`, `#maint`)
opens a view directly.

## Files

| File | Content |
|---|---|
| `index.html`, `style.css` | the page |
| `js/params.js` | generated by `tools/gen_params.py` from [docs/params.json](../docs/params.json), the single parameter table (design report A13): do not edit |
| `js/protocol.js` | NRPN and SysEx encoding (docs/sysex.md), shared by the app and the emulator |
| `js/emulator.js` | the emulated instrument: programs, parts, edit buffers, cards, voice allocation over the parts' slot masks |
| `js/synth.js` | the emulator's sound (Web Audio) |
| `js/links.js` | links: emulator, Web MIDI, Web Serial (console) |
| `js/app.js` | the views and the model mirrored from the instrument |
| `test/test.js` | protocol and emulator tests: `node app/test/test.js` |
| `test/synth_test.html`, `test/run_browser.py` | offline render of the sound engine in headless Edge / Chrome: `python app/test/run_browser.py` |

After a change of `docs/params.json`: `python tools/gen_params.py`, then the tests.

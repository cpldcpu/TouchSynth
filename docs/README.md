# TouchSynth documentation

Everything about the design, its simulation and the measurements on the first board. Start with the
[design report](report/touchsynth_report.pdf); the Markdown documents are the working versions of its
chapters.

## Documents

| File | Content |
|---|---|
| [report/touchsynth_report.pdf](report/touchsynth_report.pdf) | **Design report** (LaTeX, ~40 pages): requirements, circuit, ngspice simulations, behavioural model, PCB, BOM, firmware, demo tunes and instruments, verification plan and the board 1 bring-up and test results. |
| [spec.md](spec.md) | Specification: goals, architecture, block requirements, part choices. |
| [sim_report.md](sim_report.md) | Circuit simulation report, blocks S1–S7 (oscillator, CV filters, ladder filter, VCA, touch, complete voice, power). |
| [verification_plan.md](verification_plan.md) | Verification and validation plan: bring-up steps B1–B12 and functional tests T1–T14 with limits from the simulations, plus the board 1 results. |
| [touchsynth_schematic.pdf](touchsynth_schematic.pdf) | Schematic, exported from KiCad. |
| [devlog.md](devlog.md) | Development log: every prompt of the Claude Code sessions, verbatim, and what was done in response. |
| `datasheets/` | Local copies of the WCH datasheets of the three supported MCUs (CH32V002, CH32V003, CH32V006); not in git (WCH copyright), download them from wch-ic.com. |

## report/

| File | Content |
|---|---|
| `touchsynth_report.tex` / `.pdf` | Report source and the built PDF. Build with `latexmk -pdf touchsynth_report.tex` (TeX in WSL). |
| `gen_tables.py` | Writes the tables in `generated/` (BOM, floorplan, board statistics) from the design data, so no number is copied by hand. |
| `generated/` | Generated LaTeX snippets included by the report. |
| `build.log` | Log of the last build. |

## figures/

All figures are generated by scripts; PDF for the report, PNG for Markdown.

| Files | Content | Generated by |
|---|---|---|
| `s1_*` … `s7_*` | Simulation results per block: DCO waveforms and amplitude, CV filter step response, VCF response and transient, VCA law, touch sensing, complete voice, power. | `sim/s1_dco/` … `sim/s7_power/` |
| `behav_validation.*` | Behavioural model compared with ngspice on the S6 score. | `sim/behav/validate.py` |
| `audio/` | Spectrograms of the behavioural-model feature clips and demo tunes. | `sim/behav/examples.py` |
| `pcb/` | PCB renders (top, bottom, placed) and the four copper layers. | KiCad export |
| `hw_board1_*` | Board 1 measurements against simulation: DCO pitch and amplitude, VCF tracking, resonance and low-pass, VCA law, thump and settling, hum and noise. | `tools/hw_figures.py` |
| `instr_drums.*` | Percussion: kick pitch envelope; the kettle (modal timpani on the PWM DAC) against a recorded timpani and on board 1 against the model. | `tools/instrument_figures.py` |

## results/

Measured and simulated data as CSV, the source of every figure and table.

| Files | Content |
|---|---|
| `s1_*.csv` … `s7_*.csv` | Simulation results per block, including the calibration tables the firmware uses (`s1_cal.csv` DCO, `s3_cutoff.csv` filter). |
| `s8_dac.csv` | S8: the pulse output as a PWM DAC (edge-aligned, centre-aligned, interpolated) against an ideal DAC (`sim/s8_dac/`). |
| `behav_cal.csv`, `behav_validation.csv` | Behavioural model fit and validation against ngspice. |
| `bringup_expected.csv` | Expected DC voltages for bring-up (operating point of the netlist, MCU not fitted; `sim/bringup/bringup_op.py`). |
| `hw_board1_*.csv` | Board 1 test results, evaluated: DCO pitch/amplitude, VCF tracking/resonance/low-pass, VCA gain/steps/settling, hum spectrum, and the kettle's decay on the board and in the model (`hw_board1_kettle.csv`). |
| `hw_board1/` | Board 1 raw data: loopback captures per test point (`dco_<note>`, `vca_<code>`, `vcf_cut_*`, `vcf_res_*`, `vcf_low_*`, `lpf_*`, noise, hum), trim DAC walks and the touch log. Recorded with `tools/hwtest.py`. |

## audio/

Sound examples. `_model` files are rendered by the behavioural model; `_hw` files and `hw_board1/` are
recorded from board 1's line out with an oscilloscope (oversampled and decimated to 48 kHz).

| Folder / file | Content |
|---|---|
| `features/` | 19 behavioural-model clips, one per feature (waveforms, filter, resonance, envelopes, glide, vibrato, …) and the acid demo; `manifest.json` describes each clip. MP3 kept in git; WAVs are regenerated with `sim/behav/examples.py`. |
| `s6_voice.wav` | ngspice transient of the complete voice (S6 score). |
| `hw_board1/` | First board 1 recordings: the three built-in demo tunes (acid, prelude, ode), a waveform tour and a scale played on the self-oscillating filter. |
| `demo/` | *TouchSynth Demo*, an original 7-part multitrack piece (board and model), and `drumkit_model.mp3`, a short beat with the percussion presets. |
| `pieces/` | Multitrack pieces, board and model versions: Purcell's *Queen Mary's March* (`march_*`), Bach's Toccata BWV 565, mm. 1–30 (`toccata_*`), *Aerosphere*, an original space-synth piece (`aero_*`), and the suite of the Aerosphere intro into the Toccata (`suite_*`). `kettle_model.mp3` plays the kettle, the modal timpani on the PWM DAC that the March uses (an F3–A3–C4 triad, then the March pattern); `timpani_model.mp3` is the older analog timpani preset. |

The multitrack pieces are recorded one part per take (the synth is monophonic) and mixed with
`tools/mix_parts.py` and `tools/suite.py`; the report's section *Demo tunes and instruments* describes the
method and the instrument presets.
